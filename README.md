# مهارات كتابة وتصميم العروض العربية

ثلاث مهارات لتحويل مادة مبادرة أو مقترح إلى عرض عربي مقنع، موجز، ومتقن بصرياً. تعمل بالترتيب:

| المهارة | الدور | المهارات الفرعية |
|---|---|---|
| [`deck-content-writer`](deck-content-writer/SKILL.md) | المحتوى والإقناع | بناء القصة، العناوين الحُجّية، الصياغة العربية، قاموس المصطلحات، الأمانة للمصدر، أسئلة صاحب القرار |
| [`arabic-deck-designer`](arabic-deck-designer/SKILL.md) | التصميم | اختيار الشكل البصري، التخطيط من اليمين لليسار، الخطوط والتسلسل البصري، استخراج الهوية |
| [`deck-quality-review`](deck-quality-review/SKILL.md) | الجودة والتسليم | الفحص البصري للشرائح، قائمة المراجعة النهائية، سجل التغييرات |

## المبادئ المشتركة

- المصدر الوحيد هو ما يزوّده المستخدم. لا اختراع لأرقام أو شراكات أو مستهدفات.
- الفصل بين القائم والمقترح والمستهدف والمتحقق.
- كل نقص يذهب إلى "عناصر تحتاج تأكيد".
- الرسالة قبل الشكل، والفحص البصري قبل التسليم.

## السكربتات

```bash
# استخراج الهوية (ألوان، خطوط، أحجام، شرائح نصها داخل صور)
python3 arabic-deck-designer/scripts/extract_theme.py deck.pptx

# تحويل الشرائح لصور للفحص
bash deck-quality-review/scripts/render_slides.sh deck.pptx out_dir
```

يحتاج: Python 3، LibreOffice (`soffice`)، Poppler (`pdftoppm`).

## مهارات مساندة

- **pptx**: لقراءة وتعديل ملفات PowerPoint.
- **dataviz**: لأي رسم بياني.

## المرجع

مبنية على دليل التحرير والتصميم لمشروع "مركز الوعي العقاري".
