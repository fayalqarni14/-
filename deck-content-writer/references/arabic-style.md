# معيار الصياغة العربية الرسمية

## النبرة

- عربية فصحى رسمية معاصرة بالأسلوب المؤسسي السعودي.
- واثقة ودقيقة، بلا مبالغة ولا وعود غير مسنودة.
- مباشرة: الفعل والفاعل أولاً، والحكم قبل التفصيل.

## الإيجاز

- احذف المقدمات البلاغية: "في ظل..."، "انطلاقاً من..."، "مما لا شك فيه..."، "يسعدنا...".
- احذف المترادفات المتتالية: "تعزيز وتطوير وتنمية" ← اختر فعلاً واحداً دقيقاً.
- النقطة الواحدة = فكرة واحدة كاملة.
- 3 إلى 5 نقاط في الشريحة. إن زادت، قسّم الشريحة.
- النقطة في سطر أو سطرين على الأكثر.

## توازي النقاط

كل نقاط المجموعة الواحدة تبدأ بالبنية نفسها:

- ✅ كلها تبدأ بفعل مضارع: "يوحّد... / يرشد... / يقيس..."
- ✅ أو كلها بمصدر: "توحيد... / إرشاد... / قياس..."
- ❌ الخلط: "توحيد الرسالة / يرشد المستفيد / الشراكة مع القطاع"

## الترقيم في نص التصميم

- لا نقطة في نهاية النقاط القصيرة ولا العناوين.
- علامات التنصيص المستقيمة " " عند الحاجة.
- الفاصلة العربية ( ، ) والفاصلة المنقوطة ( ؛ ) لا الإنجليزية.
- لا علامات تعجب في محتوى رسمي.

## ما يُتجنب

| تجنّب | البديل |
|---|---|
| الكشيدة في النص ("الهيئـــــة") | الكتابة العادية، والتأثير يُترك للتصميم |
| "العديد من"، "مختلف" بلا تحديد | الرقم أو الفئات بأسمائها، أو حذفها |
| "سوف" مع الأهداف | المضارع أو "يستهدف" |
| "يضمن"، "سيحقق حتماً" | "يسهم في"، "يستهدف" (ما لم يوثّق المصدر ضماناً) |
| البناء للمجهول المطوّل | الفاعل الصريح |

## الأرقام والتواريخ

- احفظ الرقم ووحدته ومصدره كما في الأصل دون تقريب.
- توحيد نوع الأرقام في العرض كله (عربية ١٢٣ أو هندية 123) وفق ما يستخدمه الملف الأصلي.
