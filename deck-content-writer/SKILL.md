# كاتب محتوى العروض الإقناعية

مهارة لتحويل مادة مبادرة أو مقترح إلى عرض عربي مقنع وموجز، يبني قناعة لدى صاحب القرار وينتهي بطلب واضح.

## القواعد الحاكمة (لا استثناء)

1. **المصدر الوحيد هو ما زوّدك به المستخدم.** لا تستخدم ملفات أو معلومات أخرى إلا بإذن صريح.
2. **لا تخترع** أرقاماً أو شراكات أو مستهدفات أو تواريخ أو أسماء جهات.
3. **فرّق دائماً** بين: القائم فعلاً / المقترح / المستهدف / المتحقق.
4. **لا تفترض** أن المبادرة معتمدة أو أن الكيان قائم إلا إذا نص المصدر على ذلك.
5. أي نقص أو تعارض يذهب إلى قائمة **"عناصر تحتاج تأكيد"** ولا يُسدّ بالتخمين.

## سير العمل

1. **اقرأ المصدر كاملاً** قبل أي اقتراح. إن كان عرضاً فيه نصوص داخل صور، حوّل الشرائح إلى صور واقرأها (انظر مهارة deck-quality-review، السكربت render_slides.sh).
2. **جرد المحتوى**: صنّف كل عنصر إلى: جوهري / قابل للدمج / للملحق / يحتاج تأكيد. سجّل رقم الشريحة أو القسم لكل عنصر.
3. **حدد الجمهور والقرار المطلوب** من المصدر. إن لم يُذكر، ضعه في "عناصر تحتاج تأكيد".
4. **ابنِ القصة** وفق `references/storyline.md`.
5. **اكتب العناوين** وفق `references/headlines.md`.
6. **اكتب النص** وفق `references/arabic-style.md` و`references/glossary.md`.
7. **اربط كل معلومة بمصدرها** وفق `references/source-fidelity.md`.
8. **أعدّ أسئلة صاحب القرار** وفق `references/decision-questions.md`.
9. سلّم بالقالب أدناه، ثم مرّر الناتج على مهارة deck-quality-review.

## قالب التسليم لكل شريحة

```markdown
### الشريحة [رقم]: [العنوان الحُجّي]

**دورها في التسلسل:** [لماذا هنا؟ وإلى ماذا تمهّد؟]
**الرسالة الرئيسية:** [فكرة واحدة]
**الحجة والدليل:** [ما الذي تُقنع به؟ ما الدليل المتاح؟ لماذا يهم القارئ؟ ما الدليل الناقص؟]
**النص النهائي:**
- [نقطة]
- [نقطة]
- [نقطة]
**التصور البصري:** [نوع التخطيط وترتيب العناصر وما يُبرز]
**المصدر:** [اسم الملف + رقم الشريحة/القسم]
**يحتاج تأكيد:** [إن وجد]
```

## صيغة التسليم الكاملة

1. **المنهج باختصار**: الرسالة الرئيسية للعرض، ومنطق التسلسل، وأهم قرارات الدمج والاختصار والنقل للملحق.
2. **المحتوى شريحة شريحة** بالقالب أعلاه.
3. **الملاحظات وسجل التغييرات** (انظر deck-quality-review/references/change-log.md).

| `references/arabic-style.md` | عند كتابة أو تحرير أي نص |
