# اختيار الشكل البصري

## الجدول الأساسي

| نوع المحتوى | الشكل المناسب | ملاحظات |
|---|---|---|
| أهداف أو فوائد متوازية (3–5) | بطاقات أو نقاط موجزة | بطاقة لكل فكرة، أيقونة فقط إن أضافت معنى |
| خطوات متسلسلة | عملية مرقمة (أسهم أو دوائر مرقمة) | الترقيم من اليمين لليسار |
| مراحل زمنية | خط زمني أفقي | يبدأ من اليمين |
| مقارنة بين خيارين أو دورين | عمودان متقابلان أو جدول | مثال: "الهيئة تشرّع ... / المركز يوعّي ..." |
| رقم محوري موثق | رقم بارز + وصف + وحدة + مصدر | المصدر بخط صغير أسفله، لا يُحذف أبداً |
| بيانات مقارنة | جدول موجز أو رسم بياني | مقياس صادق يبدأ من صفر للأعمدة |
| فئات مستهدفة | مجموعات أو بطاقات بأسماء الفئات | احتياج كل فئة تحت اسمها |
| علاقات بين عناصر | مخطط علاقة (مركز وأطراف، هرم، دوائر متداخلة) | فقط إن كانت العلاقة جوهر الرسالة |
| هيكل حوكمة | مخطط تنظيمي | مستويات واضحة، أسماء الأدوار كما في المصدر |
| مواءمة مع استراتيجية | جدول ثلاثي: الركيزة / الأولوية / الإسهام | المصدر أسفل الجدول |
| تعريف جوهري | سطر أو سطران بخط كبير ثم نقاط إن لزم | |
| تجارب مرجعية | بطاقات لكل تجربة: الاسم، الدولة، الدرس المستفاد | لا شعارات إلا إن وُجدت في المصدر |
| طلب أو قرار | شريحة بسيطة، الطلب بخط كبير، 2–3 نقاط داعمة | بلا زخرفة |
| شريحة فاصلة | عنوان القسم + سطر يربطه بما قبله | لا تستخدمها أكثر من اللازم |

## قواعد عامة

- **لا مخطط حيث يكفي نص موجز.** الأيقونات والرسوم تُستخدم حين تختصر، لا حين تزيّن.
- **نوّع التخطيطات حسب الوظيفة** مع الحفاظ على وحدة العرض (نفس الشبكة والألوان والخطوط).
- **صور العقارات** لا تُكرر كزخرفة. اختر عناصر تخدم فكرة الوعي (مثل: مستفيد يقرأ عقداً، سؤال وجواب، علامة تحقق).

## قواعد الأرقام والرسوم

- الرقم ووحدته ومصدره يبقون كما في الأصل.
- المحور يبدأ من صفر في الأعمدة. لا تقطع المحور لتضخيم الفرق.
- لا رسوم ثلاثية الأبعاد ولا دوائر لأكثر من 4 أجزاء.
- اللون يميّز فئة واحدة مهمة، والباقي رمادي.
- استخدم مهارة dataviz لأي رسم بياني.
